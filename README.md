# 경영지원 업무 보드

인사 · 총무 · 회계 · 정부지원사업 · 법정 신고 일정을 한 화면에서 관리하는 경영지원 업무 총정리 툴입니다.
설치나 서버가 필요 없습니다. `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 기능

| 메뉴 | 내용 |
|---|---|
| 대시보드 | 오늘 기준 다가오는 일정(D-day), 기한 지난 항목, 확인할 사항(기한 지난·방치된 요청, 증빙 누락·계약 만료·집행률·연차 소멸·백업) |
| 일정 | 월간 달력 + 목록. 법정 일정, 할 일, 요청 처리 기한, 검토 과제 결정 기한, 지원사업 보고 기한, 계약 만료, 수습 종료, 입사 기념일, 휴가 |
| 업무 | 할 일(하위 작업 체크 포함), 상시 업무 매뉴얼(필요시 처리), 검토 과제, 이슈 기록(원인·재발 방지) |
| 요청·결재 | **지출 요청 · 이체확인증 · 서류 발급 요청 워크플로우**. 접수 → 검토 → 승인 → 처리중 → 완료(보류·반려) 단계 관리, 종류별 처리 체크리스트 자동 생성, 처리 기한 D-day, 완료된 지출 요청은 한 번에 지출로 등록. 자주 요청받는 서류별 발급처 안내 |
| 인사 | 직원 명부, 근속 기간, **연차 자동 계산**(입사일 기준), 휴가 기록, **입·퇴사 체크리스트 자동 생성** |
| 회계·지출 | 지출·증빙 기록, 계정과목별 집계, 3만원 초과 적격증빙 누락 경고, 개인카드 정산 추적 |
| 정부지원사업 | 공고 검토 → 신청 → 협약 → 정산 단계 관리, 사업비 집행률(지출과 연결), 보고·정산 기한 |
| 총무 | 계약·구독 만료/통보 기한, 월 고정비 환산, 자산·비품 대장 |
| 설정·백업 | 회사명·급여일·공휴일, 사용자 반복 일정(매일·매주·매월·분기·매년), JSON 백업/복원, CSV 내보내기 |

### 기본으로 들어 있는 법정·정기 일정 (12월 결산 법인 기준)

원천세·4대보험료(매월 10일), 4대보험 취득·상실 신고(매월 15일), 급여일, 간이지급명세서(매월 말일),
부가세 예정·확정(1·4·7·10월 25일), 연말정산(1~3월), 보수총액 신고(3월), 법인세(3/31), 법인지방소득세(4/30),
주민세 사업소분·법인세 중간예납(8/31), 법정의무교육 점검(11월) 등.
기한이 주말·공휴일이면 다음 영업일로 계산하며, 공휴일 목록은 설정에서 수정할 수 있습니다.

## 사용 방법

1. 이 저장소를 내려받아 `index.html`을 더블클릭해 엽니다 (Chrome / Edge / Safari 최신 버전).
2. 처음에는 대시보드의 **샘플 데이터로 둘러보기**로 기능을 확인한 뒤, 설정에서 초기화하고 실제 데이터를 입력하세요.
3. 직원 → 계약 → 지원사업 순으로 등록하면 관련 기한이 대시보드와 달력에 자동으로 나타납니다.

### 요청·결재 워크플로우 사용법

1. 직원·거래처·기관에서 지출 승인, 이체확인증, 재직증명서 등 요청이 오면 **요청·결재 → + 지출 요청 / + 이체확인증 / + 서류 발급**으로 접수합니다. 종류에 맞는 처리 체크리스트가 자동으로 채워집니다.
2. 목록의 **→ 다음 단계** 버튼으로 접수 → 검토 → 승인 → 처리중 → 완료 순으로 넘기고, 체크리스트를 펼쳐 처리한 항목을 체크합니다. 보류·반려는 수정 화면에서 상태를 바꾸고 사유를 메모에 남깁니다.
3. 처리 기한을 넣어 두면 대시보드와 달력에 D-day로 표시되고, 기한이 지났거나 접수 후 3일 이상 검토되지 않은 요청은 대시보드 "확인 필요"에 올라옵니다.
4. 지출 요청을 완료하면 **지출 등록** 버튼으로 금액·거래처·계정과목·지원사업 재원이 채워진 지출 기록을 바로 만들 수 있습니다.

> GitHub Pages(Settings → Pages → Branch 선택)를 켜면 웹 주소로도 열 수 있습니다.
> 단, 저장소가 공개(public)라면 코드만 공개되고 **입력한 데이터는 각자의 브라우저에만 저장**됩니다.

## 기존 업무 관리 툴 데이터 가져오기

이전에 쓰던 업무 툴의 백업(`routine` / `later` / `issues` / `ideas` / `days` 키를 가진 JSON)은
**설정·백업 → 백업 불러오기**에서 선택하면 자동으로 변환되어 현재 데이터에 추가됩니다.

| 기존 항목 | 보드에서 |
|---|---|
| routine (일·주·월·분기·연 정기) | 사용자 반복 일정. 매일 루틴은 대시보드 "오늘 루틴"에, 나머지는 달력에 표시 |
| routine (비정기, 시기 "필요시") | 업무 → 상시 업무 (처리 방법·참고 자료 유지) |
| routine (비정기, 그 외) · days의 adhoc | 업무 → 할 일 (하위 작업·상태·우선순위 유지) |
| later | 할 일 (상태 "보류") |
| ideas | 업무 → 검토 과제 |
| issues | 업무 → 이슈 기록 |
| days의 루틴 완료 체크 | 해당 날짜의 루틴 완료 기록 |

## 데이터 보관 주의

- 데이터는 브라우저 `localStorage`에만 저장됩니다. 브라우저 데이터 삭제, PC 교체, 다른 브라우저 사용 시 보이지 않습니다.
- **설정·백업 → 백업 파일 내보내기**로 JSON 파일을 받아 접근이 제한된 회사 드라이브에 보관하세요. (14일 이상 백업이 없으면 대시보드에 알림)
- 주민등록번호·계좌번호 등 민감한 개인정보는 입력하지 마세요.

## 참고

- 세법·4대보험·노동법 관련 안내와 일정은 업무 참고용입니다. 실제 신고 전 홈택스, 4대사회보험 정보연계센터 공지와 세무·노무 대리인 안내를 확인하세요.
- 연차는 근로기준법 제60조(입사일 기준)로 계산하며, 출근율 80% 미만, 회계연도 기준 운영, 상시 5인 미만 사업장 등은 반영하지 않습니다.
